- [03 品牌工作室](http://127.0.0.1:8099/?design=studio)：国际化留白、衬线大标题、丝带视差和跟随聚光。

数字星图已分为首页、技术服务、合作流程、公司、资质和联系六区，固定顶部导航按区定位并显示当前项。三个无边框节点入口轮流呼吸，背景节点已加快、加大移动；第四版入口文字加大并支持跳转与点击脉冲。两版入口悬停或键盘聚焦时暂停轮换，移开后继续。第四版在能量核心附近移动鼠标、点击空白处也可体验反馈。触屏支持轻触扩散波，原生纵向滚动保留。

方案02电路背景沿用原有SVG细线、节点、沿线流光和节点扩散动效，仅更换各区连接形状：服务为芯片与电阻，流程为三个串联测试节点，关于我们为接口总线，资质为焊盘与过孔阵列，产品为蜂窝、电容、电阻及晶振组合，新闻为脉冲与波形观察点，联系为汇流端口。元件与路径端点直接连接，不使用整张图片扫光。正文下方保留至少24px间距，底部电路随容器等比展开、最大1640px，装饰高度限40–134px；缩小元件并延伸两侧线路。上方在既有留白内加入不同走向的短电路线与沿线流光，桌面40px高、手机28px高，左右交错呼应下方，不额外撑高区块。线路以蓝、青为主，少量紫色点缀；芯片与接口使用浅蓝青紫渐变填充和清晰蓝色轮廓，保持细线、边缘渐隐与原沿线动效。保留重点文字配色和首屏星图；04维持既有深色主题。 实际检查与测试边界见[设计检查](design-qa.md)。

方案02/04资质区只展示高新技术、创新型中小企业证书图片与名称，通过左侧“查看更多”统一进入资质列表；下方横向滚动区展示8项第三方AAA信用评价和17项软件著作权，支持自动往返、手动拖动、悬停与键盘聚焦暂停；隐藏滚动条，移除分组按钮及数量说明，仍支持全局暂停。方案02/04均将信用与知识产权分组显示，分类字号12px、名称14px，不显示“拖动浏览”；1100px以上两组并列，窄屏上下排列。列表页按类别展开查看。原件可查看，首页不再罗列证书编号及机构信息；01/03保留原状。

方案02/04页脚已统一排版并预留ICP备案、公安备案查询链接。后台「主题 → 屹鑫元企业官网 → 页脚与备案」填写两个真实编号后，前台自动显示为链接；查询地址可单独修改，未填号时显示查询入口。

前台字体统一本地托管：Noto Sans SC、Inter、Source Serif 4，均为SIL OFL 1.1。许可证和文件来源/哈希保留在主题 `fonts/`，不请求外部字体CDN。

日常维护无需构建前端。首次新增：页面 → 添加页面，填写标题和英文文件夹名，选择父栏目与模板；在发布设置把「已发布」设为「是」后保存。可复制同类内容减少反复选择模板。媒体可拖入或点击上传，详情自动使用首张图片，PDF 自动提供链接。

企业新闻、产品库、客户案例的全站开关位于「主题 → 屹鑫元企业官网 → 配置 → 可选栏目开关」，主题缺省值全部完全关闭，当前本地配置已开启并允许样例预览。关闭时隐藏首页与导航，列表和详情（包括别名）返回404，后台内容保留且可编辑；四套方案共用开关。开启后只有已发布、非演示（或获准展示的预览样例）且允许在当前方案展示的内容才进入首页和导航，无内容时入口仍隐藏，列表显示空状态。原试用新闻、案例仍为演示草稿，不作为企业成果。

产品库支持关键词与分类组合筛选、结果数量、无结果提示、清空筛选和独立详情。新增时选择产品库为父栏目、Product为模板；分类名称相同自动归组。先维护真实产品资料，再发布并开启栏目。软件著作权证书继续属于资质，不自动转成可售产品。Cloudflare Pages是静态快照，开关与内容变更需重新导出、打包和上传才能影响分享链接；当前方案预览已重新发布到原Pages项目。
