基于 Grav 的轻量企业官网，带中文后台。当前已使用企业资料制作四套可切换的本地候选模板；尚未部署到正式服务器。

- [01 数据光流](http://127.0.0.1:8099/?design=flow)：深色科技与蓝紫光流。
- [02 数字星图](http://127.0.0.1:8099/?design=constellation)：可悬停、可点击的动态星图。
- [03 品牌工作室](http://127.0.0.1:8099/?design=studio)：国际化留白、衬线大标题、丝带视差和跟随聚光。
- [04 数字脉冲](http://127.0.0.1:8099/?design=nexus)：独立光点轨道、鼠标避让、点击扩散波，全页深色科技风格。
- [中文后台](http://127.0.0.1:8099/admin)。右下角可切换预览方案；后台主题设置可选择默认方案和关闭预览工具。

后续仅迭代02数字星图和04数字脉冲，01/03保留现状。02/04导航统一为首页、技术服务、合作流程、关于我们、企业资质、联系我们；两版均固定导航并高亮当前栏目，保留各自配色。后续区块大屏背景全宽，正文与首屏居中对齐。02/04栏目改称「技术服务」「合作流程」，可通过首页专用字段维护。

数字星图已分为首页、技术服务、合作流程、公司、资质和联系六区，固定顶部导航按区定位并显示当前项。三个无边框节点入口轮流呼吸，背景节点已加快、加大移动；第四版入口文字加大并支持跳转与点击脉冲。两版入口悬停或键盘聚焦时暂停轮换，移开后继续。第四版在能量核心附近移动鼠标、点击空白处也可体验反馈。触屏支持轻触扩散波，原生纵向滚动保留。

方案02/04的后续区块分别延续浅色星图、深色能量曲线，采用轻量SVG与CSS缓慢位移，离屏或暂停时停止。进入或刷新首页默认回到首页；页内栏目点击与前进/后退保持可用。

方案02/04资质区直接展示高新技术、创新型中小企业证书图片；8项第三方AAA信用评价在独立折叠分组中展示。原件可查看，首页不再罗列证书编号及机构信息；01/03保留原状。

方案02/04页脚已统一排版并预留ICP备案、公安备案查询链接。后台「主题 → 屹鑫元企业官网 → 页脚与备案」填写两个真实编号后，前台自动显示为链接；查询地址可单独修改，未填号时显示查询入口。

前台字体统一本地托管：Noto Sans SC、Inter、Source Serif 4，均为SIL OFL 1.1。许可证和文件来源/哈希保留在主题 `fonts/`，不请求外部字体CDN。

已确认需求、资料采用边界、内容维护、动效与未决事项见 [官网模板方案](TEMPLATE.md)；本轮视觉验证见 [设计检查](design-qa.md)。

```powershell

.\scripts\start.ps1
.\scripts\stop.ps1
```

复用 PHP 8.4.26：`D:\devtool\scoop\apps\php84\current\php.exe`。Grav 2.2.11、Admin2 2.1.37 来自官方完整包。启动脚本仅监听 `127.0.0.1:8099`，PHP 扩展配置仅作用于本站；这是开发服务器，不是正式部署方式。
